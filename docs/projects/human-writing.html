KKKKhazix/human-writing — 中文"活人感"写作 Skill

一句话定位

让 AI 写的中文读起来像一个具体的人在说话——知道一些事，有判断，偶尔岔开一句，还能接回来的通用创作与改稿 Skill。

它解决的问题

目标用户是中文创作者（知乎、公众号、博客、论坛、小说、口播、评测、科普等）。痛点：AI 写的中文有个通病——"读完觉得挺流畅，但说不出是谁写的"——缺乏个人风格、判断和节奏感，充斥报告腔、模型腔和翻案句。human-writing Skill 想治的就是这件事：让 AI 输出有"活人感"——像具体的人在说话。

为什么值得关注（2026-08-06）

这标志着中文 agent skill 品类的出现——中文社区从"使用 agent"进入"制造 skill"阶段。1 天破千星（1,006⭐ / 98 fork）说明中文创作者对"去 AI 腔"有真实痛点需求。与 open-kimi-ppt-skill（逆向 Kimi Slides→PPT）同日爆发，两者共同构成中文 agent skill 的首批代表项目。关键差异化：这不是通用工具，而是面向中文写作垂直场景的 skill，管材料/推进/中文三件事 + 初稿后逐段检查。

热度来源判断

  • 真实需求信号：1 天 1,006⭐ / 98 fork。"去 AI 腔"是中文创作者社区的高频痛点（知乎/公众号大量讨论"AI 文特征"），skill 形式让这个痛点可操作化。98 fork 说明有用户在尝试部署/定制。
  • 话题性成分：首日数据，1 天破千星可能含话题性爆发成分。需观察 08-07 是否回落。

关键技术亮点亮点

  1. 三轴写作控制：材料（现实写作核准事实/数字/引语，虚构写作检查人物/行动/因果）、推进（每段带来新东西——新事实/新动作/新例子/新后果，写过的不重复）、中文（白话打底，在意词序和停顿，清报告腔/模型腔/翻案句）。这三个维度覆盖了"AI 文"的主要缺陷。
  2. 初稿后逐段检查：Skill 写完初稿后逐段检查"原地转圈"（重复解释）、砍掉重复、调整长短句节奏、拦住冒号滥用、破折号、"不是……而是……"翻案腔和常见 AI 黑话。检查脚本只管已写明的硬规则，不替用户决定风格。
  3. 现实/虚构双模式：现实题材（材料不够就查/追问/缩短篇幅，绝不车轱辘话凑字数）vs 虚构题材（自由创造人物和情节，但每个场景仍要有目标/动作/变化）。
  4. 场景覆盖广：README 列出知乎回答、公众号文章、博客、论坛帖、人物故事、科普、评测、小说、口播等场景。

架构启发

human-writing 的设计哲学是 "规则约束而非风格替代"——skill 不替用户决定风格，只执行硬规则（查重复、清模型腔、核事实）。这与"让 AI 模仿风格"的思路不同：它假设风格来自人类的判断和材料选择，AI 只需在执行层避免"机器味"。对架构师的启发：垂直 skill 的价值在于把领域知识编码为可执行规则，而非让 AI 自由发挥。

定位判断

属于 L5 应用层/skill 层，是 agent skill 生态中的中文写作垂直 skill。与通用 skill（anydoc 做文档解析、skill-recorder 做技能提取）不同，human-writing 是面向特定创作场景的领域 skill。

风险 / 局限 / 泡沫点

  1. 首日数据，持续性未验：1 天破千星可能是话题性爆发（"去 AI 腔"是热门话题），需观察 08-07 增量是否回落到正常水平。
  2. 写作质量需独立验证：三轴控制（材料/推进/中文）和逐段检查的效果为 README 自述，未独立验证实际生成质量（不同场景下的"活人感"是否真实）。
  3. 强中文场景，跨语言适用性低：skill 的规则（报告腔、翻案句、"不是……而是……"）针对中文写作特征，英文场景不直接适用。
  4. 检查脚本为启发式：逐段检查"原地转圈""冒号滥用"依赖启发式判断，复杂文体的误报率未披露。

与同类项目的关系

  • vs open-kimi-ppt-skill（530⭐）：同日爆发的中文 agent skill，但 human-writing 面向写作（文本生成），open-kimi-ppt-skill 面向演示（PPT 生成）。两者共同构成中文 skill 品类。
  • vs skill-recorder（1,944⭐）：skill-recorder 是通用 skill 创作工具（录屏→Skill），human-writing 是具体的领域 skill。skill-recorder 是"造 skill 的工具"，human-writing 是"被造出来的 skill"。
  • vs anydoc（4,688⭐）：anydoc 是基础设施 skill（文档摄入），human-writing 是创作 skill。层次不同。
