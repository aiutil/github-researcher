chenglou/handwired
chenglou/handwired——Handwired: Turn your regular JavaScript code into a neural net; no training, exact, yet also fully differentiable；TypeScript · MIT · 12747 KB · chenglou · README 开门见山「A program's made of if-else, loops, and state. Handwired transforms them into matrix multiplication + reglu over floats + We then collect the + and * and relu into a giant matmul, and either run it on JS or WebGPU, for fun」+ because we basically only use these 2 primitives: the full program stays differentiable + the weights don't need training since they're written manually + existing gpu techniques, such as fusion, sparsity, reordering, have a great time optimizing such minimal primitives + this unlocks lots of funny use-cases, like: unfreezing the weights and train them (what does that even do? Let's find out!) + attaching a specific frozen program to a generic neural net and train end-to-end (now a nanoGPT can do both Shakespeare and your particular UI?) + achieving GPU-level of parallelism with JS code that was written in a traditional single-threaded way (see the JSON search demo that runs in milliseconds over 100k documents) + Demos live https://chenglou.me/handwired/ + git clone && bun install, then bun start to run them locally + Check docs/ + src/ + template/ to get started! (lab/ is a bunch of old experiments you can check or ignore)

feder-cr/git-ai
feder-cr/git-ai——gitai: Git designed for AI agents；Go · MIT · 12343 KB · feder-cr · README 开门见山「Anthropic built Scion, a faster version control system for coding agents, and described it in Redesigning source control: a server-centric system built for hundreds of agents that read, write and land code at the same time. Scion is internal to Anthropic and is not available to the public. So I built gitai: an open-source version of that design that anyone can run, and that the community can improve and maintain together. MIT licensed. Vendor neutral: the server never calls a language model, and every AI feature works with any provider, or none.」+ Scion 的 ideas implemented: Always-online clients that fetch exactly what they need (ObjectService + graft clone + graft sparse materialize only the paths you ask for) + Source control as an API (blame + path history + ancestry + code search server-side and memoized as derived data) + Landing without a merge queue (UserLand rebases a change onto the current tip and lands with compare-and-swap; concurrent lands on one branch batched into a single reference update) + Automatic conflict resolution (resolvers via versioned, vendor-neutral protocol; any LLM provider, deterministic tool, or none) + Changeset log + Storage core (SQLite or PostgreSQL + compare-and-swap per reference + packs in object storage file/S3/GCS/Azure + stateless servers any node can rebuild) + Test after landing (graft-verify) + Monitoring agents (superfans) + Agent-friendly review + Agents as first-class users + Strict cache tiers (graft-cache) + Started as fork of Gitaly (the GitLab Git RPC server MIT) + Quick start Linux or macOS + Go 1.26 + a C toolchain + Meson and Ninja + make build + examples/graft/quickstart.sh + apt/LLM vendor-neutral + 5 topics ai-agents/coding-agents/git/golang/scion/version-control

Tencent-Hunyuan/Hy-Memory
Tencent-Hunyuan/Hy-Memory——Hy Memory: Production-grade dual-system cognitive memory for LLM agents；Python · Apache-2.0 · 17763 KB · Tencent Hunyuan · README 开门见山「Hy Memory (https://memory.hunyuan.tencent.com/) is a production-grade dual-system cognitive memory engine and Python SDK (hy-memory) for self-evolving LLM agents, providing specialized memory pipelines across three task scenes: hierarchical long-term cognitive memory for Chat, two-layer fact and reusable-experience memory for Working, and version-evolution diff-chain tracking for Coding. Built on top of Hy Memory, MemHub is a local-first desktop and CLI product that unifies conversation history and coding traces from user-authorized AI applications (such as Claude Code, Cursor, Codex, OpenCode, and Qwen Code) into a single managed runtime and local data directory, enabling governed cross-application memory recall.」+ Released Hy Memory 2.0 (hy-memory==2.0.2) on PyPI + Open-sourced Hy-Memory-30B-A3B on Hugging Face + technical report on attributed reinforcement learning for long-term memory writing (arXiv 2610.22196) + CMB: A Coding Memory Benchmark for Long-Horizon and Interleaved Coding Agents (submitted to ICLR 2027) + Memory Beyond Recall: A Dual-Process Cognitive Memory System for Self-Evolving LLM Agents accepted at EMNLP 2026 + Quick start pip install hy-memory==2.0.2 (core includes ChromaDB and Kuzu) + pip install hy-memory[qdrant]==2.0.2 + pip install hy-memory[faiss]==2.0.2 + pip install hy-memory[graph]==2.0.2 + pip install hy-memory[mysql]==2.0.2 + pip install hy-memory[rerank]==2.0.2 + pip install hy-memory[all]==2.0.2 + Only an LLM and an embedding endpoint are needed; any OpenAI-compatible service works
