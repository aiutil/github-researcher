deeplethe/solid-glass
deeplethe/solid-glass——Solid Glass: A design system for AI applications. Material, physical, tactile, technical；TypeScript · MIT · 17518 KB · DeepLethe + 13 items registry + Built on shadcn/ui (Base UI) + React 19 + Tailwind CSS 4 + Official site deeplethe.github.io/solid-glass + One stylesheet. Solid Glass is one stylesheet. It finds each part of a shadcn/ui component by the data-slot and the classes it already carries, so the components you have need no changes + stands between flat design and liquid glass. Flat is an opaque block with no finish to speak of; liquid glass is nearly clear, and on a page with a lot of text the reader is always fighting the background for the words. Solid Glass lets only an outline through: enough to know it is glass, not enough to get in the way of reading + AI applications are built around information that is constantly changing — responses streaming in, agents performing tasks, and decisions waiting for human input. Solid Glass keeps the interface calm and readable. Neutral surfaces reduce visual distractions, depth establishes hierarchy, and color and motion are reserved for meaningful feedback + blocks：whole screens made of the components（agent workspace: sessions, the thread, files and background tasks）+ 4-axis design language (Tactility / Precision / Physicality / Materiality) + Light/Dark + Material page shows how a pane is made + Create page lets you turn the dials + Start from a shadcn/ui project (React 19, Tailwind CSS 4, the Base UI components) + 3 天 590⭐ ⑂5 fork/star 0.8%。
