本日最值得记的判据修正，是把「投放体」从一个**静态形态**升级成一个**可运行的自动化流水线** —— ⭐⭐⭐⭐⭐ 在 `created:2026-11-14` 的 300 个候选里，**286 个（95.3%）共享同一批 README 全文 md5**，被拆成三个族群（`ai--manus2.0` 114 个 / `IPTV_Player_2.0` 111 个 / `GitHub-Copilot-app` 61 个），且**每个族群内部的所有仓库都指向同一条 Dropbox 链接**（`ManusStudio2.0.rar`、`IPTVPlayer2.0.rar`、`GitHub_Copilot_app.rar`）—— ⭐⭐⭐⭐⭐ **即「md5 相同」这一判据在本日被证伪了一半：真正稳定的指纹不是 README 的字节，而是 README 里那一条下载链接**。⭐⭐⭐⭐⭐ 而与这三族同框的 `-desktop` 族（本日 5 个：Malware Defender / Topaz Video AI / iZotope RX 11 / Adobe Acrobat PDF / Leonardo AI）**暴露了更硬的一层：它们的「活跃度」是自动生成的** —— 每个仓库都有一个随机名的 GitHub Actions 工作流（`SP7LDgUHone.yml` / `mmZDs9dJzawUKR.yml` / `hi6b2Xefut.yml` / `F1fAks7Y8Hdu0.yml` / `J5zzALI4By.yml`），工作流名是随机串（`YAqWuDoGTdQ` / `P015SrpLujreU` …），内容是 `actions/github-script@v7` 里一段**随机词组合 + 随机数**的提交消息生成器，往 `.github/<随机名>` 文件里追加一行时间戳；⭐⭐⭐⭐⭐ **实测该仓库的提交历史是 `optimize revert sync (5102)` / `monitor docs enhance (3709)` / `improve validate retry (4810)`，时间戳每次都变** —— ⭐⭐⭐⭐⭐ **即「push 频率」与「commit 数量」这两个最常用的活跃度判据，在本日被证实可以由一个 30 行的定时脚本凭空制造**。⭐⭐⭐⭐⭐ 与之并列的第三个发现是**一批「零代码但高订阅」的仓库**：本日 7 个仓库（`rob-run-private-cheat` 68 subs / `wallet-security-checker` 50 subs / `sims4-updater` 24 / `TradePilot` 24 / `Wallet-Hunter` 24 / `crypto-panic` 24 / `Fragment-Sniper` 24）**整棵树只有 `LICENSE` + `README.md` 两个文件、0 个代码文件**，⭐⭐⭐⭐⭐ 而它们的 **7 个 owner 账号中有 6 个创建于 2026-09-21T17:23:39Z–17:25:16Z 的 97 秒窗口内**、每个账号各有一个随机名 + 0⭐ + ~1KB 的占位仓库 —— **即「subs 高」在本日第一次被证明可以是纯订阅农场的手动产物，且它与「star 高」完全正交**。⭐⭐⭐⭐⭐ 而与这三批同框的四个真项目，恰好给出四种**互不重叠**的诚实形态：`hikaku-io/hikaku-extension`（283⭐ · 87 files · Apache-2.0 ·
