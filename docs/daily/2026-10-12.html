Top 1：wheresryan22/anatomy——Claude Code skill 物化技术概念

  • 架构亮点： 用 Claude 作为「教学物化」引擎——L发明物理对象（token bucket = 弹子锁），L自动拆分 SVG 小件，L自动渲染 isometric 相机，L自检缩关节。所有数字（cache key 状态、gantry 喷头位置、Raptor 2 Pc 300 bar 230 tf）来自同一模型驱动部件。
  • 差异点： 区别于 Mermaid（静态图）、Manim（视频渲染）、artifacts-of-thought（多模态输出），Anatomy 把「工作对象的视觉表达」作为一等公民——读数 + 动效 + 自检 + 0 依赖。
  • 可借鉴： 任何团队文档/技术博客/landing page 都可植入 /anatomy skill 把抽象概念物化。
  • 风险点： token bucket、gantry、Raptor 2 是 README 给的 examples，其他概念（数据库索引、CAP、cache coherence）物化效果未在档案中验证；shaders 是否默认启用、WebGL 兼容性 fallback 未在档案中明示。

Top 2：tcchen2026/VibeOffice——浏览器 Office 2003 + lossless save

  • 架构亮点： 三个独立应用（Quire/Ledger/Lectern）+ Office 2003 经典 UI + lossless save 算法（只序列化用户改过部分，未编辑字节级透传）+ Compatibility Checker 警告 + 4,697 真实文件 LibreOffice/POI/Open XML SDK 端到端测 + 纯 HTML/JS 无 build + AGENTS.md 设计规则。
  • 差异点： 区别于 Microsoft 365（强账号 + 服务化）、LibreOffice（桌面安装）、OnlyOffice（服务端）、TinyMCE（不是真 .docx 解析），VibeOffice 是首次严肃的「无服务器 + 无账号 + 纯前端 + Apache-2.0」路径。
  • 可借鉴： 任何团队可自部署 VibeOffice 作为内部 office 工具，无需付费 Microsoft 365 即可打开/编辑/保存 .docx/.xlsx/.pptx。
  • 风险点： Office UI 控件库来源（自研/CodeMirror/ProseMirror）未在档案中明示；具体 OOXML 解析/序列化库选择、partial diff 算法未在档案明示；协同编辑未在档案中提及；Chrome/Edge 之外浏览器兼容策略未在档案明示。
