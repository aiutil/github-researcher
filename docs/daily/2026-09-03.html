关键证据 vs 推断： 1,419⭐ / 54 forks / 324KB / Go / MIT / created 2026-08-22 / pushed 2026-09-02——GitHub API 当日截取；3.8% fork/star 偏低但 1.4k⭐ 仍说明在 12 天内达到中等曝光；纯 Go 实现 + 324KB 说明是 CLI / library 而非 GUI。风险： 与 anti-detect 浏览器厂商形成"检测 / 反检测"军备竞赛，长期可能失效；道德 / 法律边界（合法反欺诈 vs 隐私侵犯）需自评；商业化 anti-detect 产品本身已是灰色地带。
