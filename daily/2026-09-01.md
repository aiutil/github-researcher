## 风险与机遇

- **风险 1：PRAXIST License NOASSERTION 的合规风险**——商业采用前必须读 LICENSE；scientific agent 类项目的"benchmark 宣称"复现性历来需独立测试；论文与代码版本对应关系需核验
- **风险 2：threeui 商业版 vs Community 版本边界模糊**——商业 threeUI 独家组件 / 商业授权 / 高级功能边界需读 LICENSE 与官网核验；40.8MB 资产对自托管网络成本不友好
- **风险 3：Agent Skill 设计品类的版权边界**——ip-as-logo-skill（IP mascot logo）/ mono-color-skill（编辑设计海报）等"设计 skill"涉及 IP 形象、字体、图片等版权问题；采用方必须自评合规风险
- **风险 4：团队级 harness 的开源承诺可持续性**——CopilotKit（商业 SaaS）/ yetone（个人）/ yc-software（YC 投资）/ ApodexAI（创业）四方势力同时押注但都最终走向商业 SaaS 模式；开源核心层的承诺可持续性需观察
- **风险 5：MCP 系统级调试的合规边界**——x64dbg-mcp-server 把 AI 与 Windows debugger 直连，二进制分析 / 漏洞研究 / 恶意软件分析的合规边界（美国 EAR / 欧盟 dual-use export / 中国《网络安全法》）需采用方自评
- **风险 6：DSH 生态的地缘政治风险延续**——DSH 生态从"插件"扩展到"报告 + 评估 + 桌面挂件"，但中国 AI 开源合作的监管不确定性是潜在持续风险
- **机遇 1：Autonomous research / Scientific agent 开源对标窗口**——PRAXIST 是 2026 下半年首个进入"千日增长量级"的 scientific agent；下一波可能是"垂直领域 research agent（生物 / 化学 / 材料 / 经济学）"或"多模态 research（视频 / 音频 / 3D）"
- **机遇 2：Agent Skill 协议在「代码 / 设计 / 写作 / 研究」四大方向都被验证**——下一波可能是"法律 / 医疗 / 金融 / 教育"等垂直行业 skill；Agent Skill 协议标准化窗口已开
- **机遇 3：团队级 harness 多源合流的产品化窗口**——OpenBot + cumora + qm + FrontierAgent 四方势力同时押注，下一波可能是"垂直行业版（律师 / 医生 / 设计师 / 客服）"或"企业级 RBAC + audit log + 合规模板"
- **机遇 4：MCP 协议的系统编程纵深**——x64dbg-mcp-server + 此前多款 mcp-server 共同说明 MCP 在系统编程/调试/逆向方向的扩展机会；下一波可能是"嵌入式调试 / 移动端调试 / 云原生调试 / 安全研究工具链"的 MCP 化
- **机遇 5：商业设计工具开源版本分发策略**——threeUI Community + Plasmic / Builder.io / animate-ui 等共同说明"商业设计工具 + 开源版本"是 2026 下半年的新分发模式，对 design engineers 群体有真实价值
- **机遇 6：DSH 生态立体化**——从"插件"扩展到"报告 + 评估 + 桌面挂件"说明 DSH 生态进入成熟期；下一波可能是"DSH 插件付费市场"或"DSH 行业垂直版本"
