**技术亮点。**

- **MOSS-Image Prompt Enhancer skill**：给 GPT-6 family agent 提供"图像 idea → caption + Layout JSON"的本地 Python 工具脚本，**不调用文生图服务**，避免循环调用

**风险。** 
- 训练数据 / GPU 集群与 SFT 配比未在 README 主页详述（需查 technical report）
