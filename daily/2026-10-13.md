- **d2r-mobile 版权 + 兼容性边界：** 仓库不携带 game content，用户必须自带 Switch release；44 台 closed beta 限定；Reign of the Warlock expansion 同步支持；具体重写指令清单、shader 翻译工具未在档案明示
- **esp32-iphone-agent 硬件 + 镜像稳定性：** USB-C to USB-C 直插 / Lightning 需 Camera Adapter；iOS 26+ 版本要求；iPhone 14 Pro Max 6GB 起步硬件要求；airplay mirroring 稳定性、AssistiveTouch 抖动未在档案明示
- **new-term-radar 单一 key 依赖 + Google Trends 滞后：** AIsa key 单一依赖；Google Trends 后 2 天数据未 settled；generic terms 14 天后回升概率未量化

**机遇：**
- **桌面 Claude 工作流 + Skills 协议生态严肃工程化（CCBaga + anatomy + craft-launcher）** 形成完整 stack：Skills 协议 + 桌面工具 + 跨平台 Rust/Tauri 严肃工程化
- **iOS native Mach-O 移植生态严肃工程化（d2r-mobile + muguet）** 形成完整方向：原生 aarch64 + Metal graphics API 重写 + 离线 shader 翻译 + 仓库不携带 game content
- **AI 桌面工具新硬件路径严肃工程化（esp32-iphone-agent）** 绕开苹果生态封闭，给极客/研究/无障碍场景新解
- **AI 应用观察工具严肃工程化（new-term-radar + Tracely-ai）** 早于 Google Trends 3-14 天发现新词 + Trace-native CI/CD 闭环
