- **核心能力**：(a) **实时人脸追踪**——检测 webcam 输入中是哪张脸；(b) **14 种会议反应**——time out / heart hands / hands over face / crashing out / dancing / nose pinch / flirty / hand up / tongue out / gasp / disgust / talking to the camera / ???；(c) **表情包贴脸**——根据反应自动贴对应表情包，按比例跟随；(d) **Zoom 虚拟摄像头输出**——通过 Zoom / Teams / Meet 的虚拟摄像头设备，整个会议能看到
- **架构师速览（精简）：**
  - 系统边界：本地 webcam 处理 + 表情包叠加 + 虚拟摄像头输出层；典型栈 OpenCV 人脸检测 + PIL / OpenGL 表情包叠加 + OBS-VirtualCam / pyvirtualcam 虚拟摄像头驱动
  - 主路径：webcam 帧捕获 → OpenCV 人脸检测 → 表情分类（用户指定或自动）→ 表情包图像合成 → 虚拟摄像头设备输出 → 会议客户端读取
  - 关键权衡：本地处理（隐私）vs 云端处理（更准）；14 种反应（开箱即用）vs 用户自定义扩展；CPU 处理（兼容）vs GPU 处理（性能）
  - 最小 PoC：`pip install itsgiving`（或 `git clone`）→ 启动本地虚拟摄像头驱动 → 在 Zoom 设置中选择 itsgiving 虚拟摄像头 → 触发不同反应测试人脸追踪
- **关键风险**：(a) **跨平台虚拟摄像头驱动**——macOS / Windows 虚拟摄像头实现差异（OBS VirtualCam、pyvirtualcam、Zoom 兼容层）；(b) **隐私边界**——本地 webcam 处理是默认路径，但若改为云端需要用户明确知情；(c) **会议礼仪**——会议中用表情包滤镜的合适场景需要规范；(d) **Snap Camera 已停服（2023）**——itsgiving 是接替者之一，与 mmhmm / Loom / OBS 虚拟摄像头的差异化需要观察
